# Histórico — integração Atrium

Este documento foi reduzido após a V2 rápida.

A integração Web com os SDKs Atrium existiu em uma etapa anterior, mas foi
retirada do runtime ativo desta versão. `/analise` agora é uma orientação local
opcional, sem engine, conversa, persistência ou chamada à Atrium.

A Cred Marvi continua sendo aplicação cliente separada do core Atrium. Nenhum
código do core foi copiado para este repositório. Os artefatos em `vendor/`
permanecem apenas como registro histórico e não são dependências do pacote Web.
