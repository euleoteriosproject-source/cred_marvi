# Histórico — provisioning Atrium

A configuração em `config/atrium/development.json` pertence a uma etapa
anterior e não é consumida pela V2 rápida. Não execute provisioning para operar
a vitrine, o catálogo, a orientação opcional ou o contato via WhatsApp.

Qualquer retomada futura de integração exige novo escopo, revisão de privacidade
e consumidor real antes de reintroduzir variáveis, SDKs ou configuração.
