# Documentação Cred Marvi

Esta documentação descreve a V2 rápida do site: vitrine comercial, catálogo,
orientação opcional e contato direto com Marlise Euleoterio.

## Estado atual

- **IMPLEMENTADO:** home comercial responsiva, catálogo único, filtros por
  público, quatro páginas específicas, WhatsApp contextualizado, orientação
  opcional sem coleta, rota legada de sucesso, SEO básico e páginas legais.
- **FORA DE ESCOPO:** backend, CRM, Supabase, protocolo, cadastro, simulador,
  análise financeira, roteamento conversacional e envio automático.
- **PENDENTE DE CONFIRMAÇÃO COMERCIAL:** FGI PEAC, produtos específicos de
  energia, saúde/benefícios e viagens, parceiros e modalidades não aprovadas.
