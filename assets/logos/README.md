# Logos

- `source/cred-marvi-logo.jfif`: referência-mestra visual, 1254×1254, 109.187 bytes.

Os arquivos foram copiados byte a byte do MVP visual autorizado. Eles permanecem rasters com fundo incorporado e não foram redesenhados, recortados ou vetorizados.

## Derivados

Nenhum derivado foi criado nesta etapa. Não havia ferramenta de otimização adequada já disponível, e instalar dependência sem consumidor real adicionaria complexidade desnecessária. Versões responsivas serão produzidas quando seu uso estiver definido.

A autoria e a licença dos arquivos ainda devem ser formalmente confirmadas antes de distribuição externa.
